# **App Name**: ProfileVault

## Core Features:

- User Authentication: Secure user registration and login to ensure private access to personal and professional details.
- Personal Details Management: Allow users to input, view, and edit their basic personal information, including name, contact details, and social media links.
- Education Details Management: Enable users to add and manage their educational qualifications, including institutions, degrees, and dates.
- Experience Details Management: Provide functionality to document and update professional work experience, including job titles, companies, and employment periods.
- Portfolio & Link Management: Dedicated section to add and organize links to personal portfolios, professional websites, or other relevant online presence.
- AI Profile Summary Generator: An AI tool that automatically drafts a professional summary or bio based on the user's entered education and experience details.

## Style Guidelines:

- Primary color: A sophisticated, clear blue (#70A0EE) for professionalism and trust. Chosen for contrast against a dark background.
- Background color: A dark, subtly blue-grey (#1A1F25) for a professional and modern dark mode aesthetic, reducing eye strain.
- Accent color: A vibrant cyan (#99EFFF) for highlighting interactive elements and calls to action, providing clear distinction and energy.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly readable qualities suitable for data-rich dashboards.
- Use clean, minimalistic line-based icons throughout the dashboard to maintain a sleek and professional interface.
- Employ a modular, card-based layout for various data sections, ensuring clear organization and an intuitive user experience within the dashboard.
- Incorporate subtle and smooth transitions for navigation elements and data updates to provide a fluid and responsive user interface.
